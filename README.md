# 백엔드 스터디

자바 기초부터 Spring Boot API와 배포까지 주차별 실습을 모아 둔 저장소입니다.

## 학기별 구성

### 1학기

- `1학기/week01`: Java 기본 문법과 메서드
- `1학기/week02`: 컬렉션을 이용한 회원 등록
- `1학기/week03`: 클래스와 예외 처리
- `1학기/week04`: 상품 API와 Spring Boot 기초
- `1학기/week05`: 도서 CRUD API

### 2학기

- `2학기/week01`: 콘솔 Todo 실습
- `2학기/week02`: Spring 컴포넌트와 Todo·단축 URL API
- `2학기/week03`: Spring Boot 배포 실습
- `2학기/week04`: SQL 조인과 제약 조건
- `2학기/week05`: 회원·게시글·단축 URL을 다루는 Spring Boot 실습

각 주차 폴더의 README에서 학습 내용과 실행 방법을 확인할 수 있습니다. Gradle 프로젝트는 해당 프로젝트 폴더에서 제공되는 `gradlew` 또는 `gradlew.bat`를 실행하세요.

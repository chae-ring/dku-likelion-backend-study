# Method & ArrayList 정리

## 개요
Java에서 **함수(Method)**는 특정 기능을 수행하는 코드 묶음이며,  
**ArrayList**는 크기가 동적으로 변하는 배열 구조이다.  

이번 학습에서는 리스트에 데이터를 저장하고, 이를 함수에 전달하여 처리하는 방법을 익혔다.

---

## 함수(Method) 개념

### 함수란
- 특정 작업을 수행하는 **코드 블록**
- 필요할 때 호출하여 사용
- 코드 중복을 줄이고 **재사용성 향상**

---

### 함수의 기본 구조

반환타입 함수이름(매개변수) { 실행 코드 return 값; }

예시  
static int mod(int a, int b) { return a % b; }

---

### 주요 구성 요소

#### 1. 반환 타입
함수 실행 후 돌려주는 값의 타입  
**void**는 반환값이 없음을 의미

#### 2. 함수 이름
함수의 역할을 나타내는 이름  
예: `printList`, `getSum`, `calculate`

#### 3. 매개변수
함수로 전달되는 입력값  
예: `int add(int a, int b)`

#### 4. 반환값
함수 실행 결과를 호출한 곳으로 반환  
예: `return a + b`

---

### 함수 호출
`int result = mod(3, 2);`

---

### static 함수 vs 일반 함수

#### static 함수
객체 생성 없이 호출 가능

#### 일반 함수
객체 생성 후 호출

예  
`MethodsExample ex = new MethodsExample();`  
`ex.hello();`

---

## ArrayList 개념

### ArrayList란
- 크기가 자동으로 늘어나는 **동적 배열**
- 데이터를 순차적으로 저장하는 자료구조

---

### 특징
- 배열과 달리 크기 제한이 없음
- 다양한 메서드를 통해 데이터 관리 가능

---

### 주요 기능

- **add()** : 데이터 추가  
- **get(index)** : 데이터 조회  
- **size()** : 크기 확인  

---

### 제네릭(Generic)
`ArrayList<Integer>`처럼 사용하여 특정 타입만 저장 가능  
→ 타입 안정성 확보

---

## 함수와 ArrayList 활용

### 전체 흐름
1. ArrayList 생성  
2. 데이터 추가  
3. 함수 호출  
4. 반복문으로 요소 출력  

---

## 정리
- **함수**는 입력을 받아 처리 후 결과를 반환하는 코드 블록  
- **ArrayList**는 데이터를 유연하게 저장할 수 있는 자료구조  
- 두 개념을 함께 사용하면 **코드 구조를 깔끔하게 분리 가능**

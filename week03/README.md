# UserRegister 회원가입 프로그램

## 프로젝트 개요

`UserRegister`는 Java 콘솔 기반 회원가입 프로그램이다.  
사용자에게 회원가입 진행 여부를 입력받고, 회원 정보를 순차적으로 입력받아 `ArrayList`와 `HashMap`을 이용해 저장한다.

## 주요 기능

- 회원가입 진행 여부 확인
- ID 입력
- 비밀번호 및 비밀번호 확인 검증
- 이름 입력
- 생년월일 6자리 입력 검증
- 이메일 입력
- 회원 정보 저장
- 가입 완료 메시지 출력
- 추가 회원가입 진행 여부 확인

## 동작 흐름

1. 프로그램 실행 후 회원가입 여부를 묻는다.
2. 사용자가 `y`를 입력하면 회원가입을 진행한다.
3. 사용자가 `n`을 입력하면 프로그램을 종료한다.
4. ID, PW, 성명, 생년월일, 이메일을 입력받는다.
5. 비밀번호와 비밀번호 확인 값이 다르면 다시 입력받는다.
6. 생년월일은 6자리인지 확인한다.
7. 입력된 회원 정보는 `HashMap`에 저장되고, 전체 회원 목록은 `ArrayList`에 저장된다.
8. 회원가입 완료 후 추가 회원가입 여부를 묻는다.

## 사용 기술

- Java
- Scanner
- ArrayList
- HashMap
- 반복문
- 조건문

## 데이터 저장 구조

회원 1명의 정보는 `HashMap<String, String>` 형태로 저장된다.

```java
{
  "username": "사용자 ID",
  "password": "비밀번호",
  "name": "성명",
  "birth_date": "생년월일",
  "email": "이메일"
}
```
